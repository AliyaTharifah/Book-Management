# 📖 Simple Book Management System

This project is an implementation of a basic **CRUD (Create, Read, Update, Delete)** system for managing book data, built as a **Single Page Application (SPA)** using React.js. The application is publicly accessible via GitHub Pages.

## 🔗 Live Demo / Access the Project

You can try the application directly using the following link:

[**Access the Book Management System on GitHub Pages**](https://AliyaTharifah.github.io/Book-Management)
*(Please ensure this URL matches your GitHub Pages deployment link.)*

---

## 📝 Project Description (Assignment Brief)

The core purpose of this project is to demonstrate a fundamental understanding of:

1.  **CRUD Operations:** Implementing essential features to create, retrieve, update, and delete book records.
2.  **React State Management:** Utilizing React Hooks (`useState`) to manage book data **in-memory** (data is stored locally in the browser's state, not a persistent database).
3.  **UI/UX:** Employing **React-Bootstrap** for a clean, responsive, and interactive user interface.

### Key Features

-   **Create:** Adding new book entries to the list.
-   **Read:** Displaying the list of books (Title, Author, Year) in a structured table.
-   **Update:** Editing the details of existing books.
-   **Delete:** Removing books from the list.

## ⚙️ How to Run Locally

If you wish to run this project on your local machine:

### Prerequisites

Ensure you have Node.js and npm installed.

### Installation

1.  Clone the repository:
    ```bash
    git clone [https://github.com/AliyaTharifah/Book-Management.git](https://github.com/AliyaTharifah/Book-Management.git)
    cd Book-Management
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the application in development mode:
    ```bash
    npm start
    ```
    The application will open automatically at `http://localhost:3000`.
